# 株式会社Sanctus ホームページ

このフォルダは、株式会社Sanctus（サンクトス）のホームページの中身です。GitHub に上げると、数分で公開中のページに反映されます。

## 更新の頼み方（Claude Code に話しかける言葉の例）

- 「主なお取引先に1社追加してください。名前は〇〇株式会社です。掲載の許可は取ってあります」
- 「お問い合わせのメールアドレスを 〇〇@〇〇 にして、ボタンを押すとメールが開くようにしてください」
- 「事業を1つ追加してください。名前は〇〇、説明は……、ご相談の例は……です。町の絵の空き地にピンも足してください」
- 「〇〇の説明を、次の文に差し替えてください：……」
- 「変更した所をブラウザで表示してください」
- 「問題がなければ GitHub に上げてください」

Claude Code は、このフォルダの CLAUDE.md（更新の決まり）を読んでから作業します。色・書体・動き・書かないことの決まりは CLAUDE.md にあります。

## ファイルの構成

| ファイル | 中身 |
|---|---|
| index.html | ページの文章と区画（区画ごとに目印のコメントがあります） |
| style.css | 色・書体・配置 |
| script.js | 動き |
| images/ | ロゴと絵 |
| CLAUDE.md | Claude Code が守る更新の決まり |

## 公開の仕組み

- 公開先：（公開後に記入）
- GitHub の main に上げると、GitHub Pages が自動で公開します（反映まで数分）
- 自社のドメインへの切り替えの手順は、別にお渡しした手引きをご覧ください

## 困ったとき

Claude Code に「ホームページの〇〇が表示されません。原因を調べて、直す方法を説明してください」のように、起きていることをそのまま伝えてください。
